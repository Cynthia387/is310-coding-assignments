# pandas-eda

This folder contains an exploratory data analysis (EDA) notebook examining 
the Top 500 "Greatest" Novels dataset.

## Notebook

**EnglishDominanceInLiterature.ipynb** — Explores linguistic, national, and 
gender bias in the Top 500 novels list compiled by OCLC. The analysis finds 
that 86% of novels were originally written in English, that US and UK authors 
dominate authorship, and that female authors are especially underrepresented 
in non-English works (~11%).

## Data

The dataset is loaded directly from a remote URL — no local download needed.

**Source:** [Responsible Datasets in Context — Top 500 "Greatest" Novels](https://www.responsible-datasets-in-context.com/posts/top-500-novels/top-500-novels.html)
