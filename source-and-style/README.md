## Assignment 1: Inspecting the Cultural Web

### Selected Digital Library

For this assignment, I selected the **Internet Archive (archive.org)** as the digital library to investigate. Our group’s cultural topic is **food**, and the Internet Archive provides access to a large collection of digitized materials related to food culture, such as historical cookbooks, menus, advertisements, and household guides.

Website:  
https://archive.org/

---

### What web technologies were used?

By inspecting the website in the browser and reviewing related repositories on GitHub, the Internet Archive website appears to be built using standard web technologies including:

- **HTML** – used for structuring the content of the pages.
- **CSS** – used to control layout, typography, and styling.
- **JavaScript** – used to enable interactive features and dynamic content loading.

When inspecting the site in the browser developer tools, the page loads multiple `.js` and `.css` files in addition to the main HTML structure. These files suggest that JavaScript is used to manage search features, navigation components, and other dynamic elements of the interface.

I also located a related repository for the website:

GitHub repository:  
https://github.com/internetarchive/www

In this repository, there are files such as:

- `index.html`
- JavaScript files in a `js` folder
- configuration files and scripts

The repository description also mentions the use of **JavaScript static files and web components**, which indicates a modern web development approach rather than purely static pages.

---

### Files that were unfamiliar

While inspecting the repository, I noticed several files that are not standard HTML files, including:

- `_redirects`
- `httpd.js`
- shell scripts such as `.sh` files

These appear to support server configuration, routing, or development tasks rather than directly representing webpage content. This suggests that the Internet Archive website uses additional infrastructure and scripting tools beyond basic HTML pages.

---

### Who built this website?

The website is built and maintained by the **Internet Archive**, a nonprofit organization dedicated to providing universal access to digital knowledge. The organization maintains a GitHub account with many repositories related to its digital library projects, including tools for book readers, APIs, and website components.

GitHub organization:  
https://github.com/internetarchive

Because the organization maintains many repositories and active development projects, it is clear that the website is maintained by a **team of developers rather than a single person**. Although it is difficult to determine the exact number of contributors, the presence of multiple repositories and commit histories suggests collaborative development.

---

### Assessment

Overall, the Internet Archive website appears to be a large-scale digital library platform built with standard web technologies (HTML, CSS, and JavaScript) combined with modern web development practices. The presence of an active GitHub organization also demonstrates that the platform is maintained collaboratively and continuously updated.

## Assignment 2: Styling the Cultural Web

For the second part of this assignment, I created a webpage that presents a digitized cultural object related to food culture in the 1940s.

The page highlights menu examples derived from **The Good Housekeeping Cook Book (1944)** and demonstrates how meals were structured during that period, including breakfast, lunch, and dinner menus.

The webpage includes:

- HTML page structure (`DOCTYPE`, `html`, `head`, `body`)
- headings (`h1`, `h2`, `h3`)
- paragraphs (`p`)
- images with captions
- lists (`ul`)
- links to the original digital source
- metadata about the object
- CSS styling for layout and design

The object is linked to the original digitized version hosted on the Internet Archive.
